# Utility Tools Collection

A collection of free, browser-based utility tools for productivity, health, education, and content creation.

## 🛠️ Available Tools

### Health & Wellness
1. **Sleep Time Calculator** (`sleep-calculator.html`)
   - Calculate optimal sleep and wake times based on 90-minute sleep cycles
   - Two modes: Calculate bedtime or wake time
   - Accounts for time to fall asleep
   - Shows multiple sleep cycle options

2. **Calorie Calculator** (`calorie-calculator.html`)
   - Calculate BMR (Basal Metabolic Rate) using Mifflin-St Jeor equation
   - Calculate TDEE (Total Daily Energy Expenditure)
   - Personalized calorie goals for weight loss, maintenance, and gain
   - Macronutrient breakdown (protein, carbs, fats)
   - Supports both metric and imperial units

### Education
3. **Grade Calculator** (`grade-calculator.html`)
   - Simple grade percentage calculator
   - Weighted grade calculator with multiple assignments
   - Letter grade and GPA conversion
   - Detailed grade scale display

### Writing & Content
4. **AI Text Detector** (`ai-detector.html`)
   - Analyzes text to detect if it's AI-generated or human-written
   - Uses heuristic analysis including:
     - Sentence length patterns
     - Vocabulary diversity
     - Common AI phrases
     - Sentence structure consistency
   - Provides detailed analysis metrics

5. **Plagiarism Checker** (`plagiarism-checker.html`)
   - Compare two texts for similarity
   - Check for self-plagiarism within a document
   - N-gram matching algorithm (3, 4, and 5-word phrases)
   - Highlights matching content
   - Similarity percentage scoring

6. **Auto Writer** (`auto-writer.html`)
   - Template-based content generation
   - Multiple content types:
     - Professional emails
     - Essay outlines
     - Social media posts (Twitter, Instagram, Facebook, LinkedIn, TikTok)
     - Blog post outlines
     - Product descriptions
     - Story outlines
   - Customizable tone and style
   - Word count and statistics

## 🚀 Getting Started

Simply open `index.html` in your web browser to access all tools. Each tool works entirely client-side with no server required.
